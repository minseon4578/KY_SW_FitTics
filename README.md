# BodySync

BMI 기반 개인 맞춤 운동 추천 시스템
> Python과 Firebase를 활용한 건강 관리 프로젝트
---

# 프로젝트 소개

BodySync는 BMI(체질량지수), 체지방률, 기초대사량(BMR) 데이터를 기반으로  
사용자 맞춤 운동 및 식단 관리를 제공하는 헬스케어 시스템입니다.

---

# 주요 기능

- BMI 계산 기능
- 체지방률 계산 기능
- 기초대사량(BMR) 계산
- 자동 칼로리 계산
- 사용자 맞춤 운동 추천
- 식단 관리 기능
- 사용자 건강 데이터 분석
